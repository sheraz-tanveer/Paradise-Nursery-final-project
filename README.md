# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is a React-based e-commerce web application that allows users to browse a wide variety of houseplants, view product details, manage a shopping cart, and calculate totals dynamically using Redux Toolkit.

## Features
- **Landing Page:** Welcoming interface with background styling and a "Get Started" button.
- **Product Catalog:** Grouped into categories with at least 6 unique houseplants, featuring thumbnails, names, prices, and interactive "Add to Cart" buttons.
- **Navigation Bar:** Persistent navbar across pages displaying links and a real-time cart item counter icon.
- **Shopping Cart Management:** Ability to increase/decrease quantities, calculate individual and total costs, and remove items.
